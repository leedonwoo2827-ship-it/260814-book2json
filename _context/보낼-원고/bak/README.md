# bak — 넘기지는 않지만 버리지도 않는 것

여기 있는 `실측.json` 은 **받는 쪽이 안 읽습니다.** 발표 쇼케이스에 넣을 것은
`<장>_원고.html` 하나이고, 이미지 스튜디오에 넣을 것은 `이미지프롬프트.json`
하나입니다. 그 둘만 위 폴더에 두고, 나머지는 여기로 내렸습니다.

## 그래도 남기는 이유

원고를 자로 잰 **근거**이기 때문입니다. 나중에 "이 장이 왜 이렇게 나왔지" 를
되짚을 때 이것 말고는 볼 것이 없습니다. 장마다 이렇게 들어 있습니다.

```json
{ "id": "sam19-09", "height": 232, "lines": 6,
  "svg": false, "table": true, "say": true, "img": true,
  "over": false, "longer": false, "empty": false, "bare": false }
```

`height` 가 507 을 넘으면 발표에서 그 장만 통째로 축소됩니다. `over`·`longer`·
`empty`·`bare` 가 그 판정입니다 — 넘침 · 줄 많음 · 몸통 없음 · 그림도 표도 없음.

## 언제 여는가

**어긋난 장이 있는데 어느 장인지 이름으로 찾고 싶을 때** 하나뿐입니다.
스물일곱 장을 눈으로 훑는 대신 `over: true` 인 항목만 걸러 보면 됩니다.

평소에는 앱이 대신 읽어 줍니다 — 현황판의 `높이 최대 387px / 507px · 넘친 장 0개`
와 원고 화면 목록의 `232px` 배지가 전부 이 값에서 나옵니다.

## 원본은 따로 있습니다

이 폴더의 것은 사본입니다. 앱이 실제로 쓰는 자리는 여기입니다.

```
D:\00work\book2json-out-260814\<NN>_<원고>\10_내보내기\실측.json
```

원고를 다시 조립하면 그쪽이 갱신되고, 이 사본은 그대로 남습니다.
