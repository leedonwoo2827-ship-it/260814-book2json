# 보낼 원고 — 다 된 것만 여기 모읍니다

이 앱이 만든 **완성본을 손에 쥐여 주는 자리**입니다. 진짜 산출물은 앱 폴더 밖
(`../../book2json-out-260814/`)에 단계별로 쌓이는데, 거기는 중간 결과가 같이 있어서
"무엇을 남에게 주면 되는가" 가 한눈에 안 읽힙니다. 그래서 **줄 것만** 여기 복사합니다.

## 지금 들어 있는 것

새뮤얼슨 『경제학』 5부 중 세 장입니다.

| 폴더 | 장 | 줄 | 그림 · 표 | 실측 |
|---|---|---|---|---|
| `19장-거시경제학-개요/` | 27장 | 123줄 | 그림 23 · 표 4 | 최대 387 / 507px · 넘친 장 0 |
| `20장-거시경제활동의-측정/` | 28장 | 136줄 | 그림 23 · 표 5 | 최대 417 / 507px · 넘친 장 0 |
| `21장-소비와-투자/` | 24장 | 118줄 | 그림 16 · 표 8 | 최대 388 / 507px · 넘친 장 0 |

19·20장은 발표 쇼케이스의 `tools/split_sections.mjs` 에 실제로 통과시켰고,
**줄 수가 양쪽에서 정확히 같았습니다**(123 · 136).

디자인은 `_assetes/DESIGN.md`(회사 템플릿)를 그린 → 파랑으로 1:1 치환해 입혔습니다.
첫 문단이 리드(굵은 파랑), 목록은 연한 파랑 사각 마커, 표는 머리행에 파란 띠,
강조는 굵게+파랑입니다. **글자 크기는 안 건드렸습니다** — 944 × 507 예산이
16px 본문 기준이라 키우면 장마다 축소가 걸립니다.

## 폴더마다 파일 셋

```
<장>_원고.html        발표 쇼케이스 → 「새 발표」 → 참고 자료 칸에 끌어다 놓으세요
이미지프롬프트.json    이미지 스튜디오 → 📋 → 「슬라이드 JSON」 탭에 넣으세요
실측.json             장마다 잰 높이·줄 수. 어긋난 장을 되짚을 때만 보면 됩니다
```

`이미지프롬프트_부족분.json` 과 `이름바꾸기.txt` 는 **해당될 때만** 생깁니다.
지금 두 편 다 처음 내보낸 것이라 없습니다 — 없는 게 정상입니다.
원고를 고쳐 다시 내보내면 그때 생깁니다.

## 넣는 순서

```
1. 원고 HTML 을 발표 쇼케이스(5178)에 넣어 장이 제대로 갈리는지 본다
     → 표지 1 + 본문 N + 마무리 1 이 나오면 맞다 (19장이면 29, 20장이면 30)
2. 원고를 눈으로 보고 고칠 것이 있으면 이 앱(5187)에서 고치고 다시 내보낸다
3. 원고가 확정된 뒤에 이미지프롬프트.json 을 이미지 스튜디오에 넣는다
```

★ **3번이 마지막인 이유**가 이 앱의 설계 이유이기도 합니다. 원고를 고치면 슬라이드
번호가 밀려서 이미 만든 `005.png` 가 남의 장 그림이 됩니다. 그래서 원고를 먼저
확정합니다. 그래도 나중에 고쳐야 한다면, 다시 내보낼 때 `이름바꾸기.txt`(번호만
밀린 장)와 `이미지프롬프트_부족분.json`(다시 그려야 하는 장)이 갈라져 나옵니다 —
**이미 그린 그림을 다시 그리지 않아도 됩니다.**
