> 슬라이드 규격: **13.33 × 7.5 in (16:9 와이드)**

## 1. 키 컬러 팔레트

화이트 배경 위에 **그린 계열이 주조색**, **슬레이트(청회색) 계열이 텍스트/보조색**으로 쓰이는 구성. 파랑은 UBION 로고·"consortium" 표기에만 쓰이는 포인트 컬러다.

### 브랜드 그린 (주조색)

| 역할 | HEX | 용도 |
|---|---|---|
| Primary Green | `#2A9760` | 카드 헤더 바, 단계 박스, 표 헤더 등 주요 도형 채움 |
| Deep Green | `#1F9155` | 제목 내 키워드 강조, 리드(요약) 문장, 큰 숫자 강조 텍스트 |
| Dark Green | `#176A3C` | 진한 강조 텍스트 (드물게 사용) |
| Green Tint 1 | `#93D0B2` | 연한 그린 도형 채움 (프로세스 중간 단계 등) |
| Green Tint 2 | `#E3F5EA` | 아주 연한 그린 배경 (KEY 메시지 띠, 강조 배경) |

### 슬레이트 뉴트럴 (텍스트·보조)

| 역할 | HEX | 용도 |
|---|---|---|
| Text Dark | `#334155` | 본문·제목 기본 텍스트 (가장 많이 쓰임) |
| Text Mid | `#475569` | 보조 텍스트 (드물게) |
| Muted | `#94A3B8` | 라벨, 캡션, 푸터, 비활성 텍스트 |
| Light Border | `#CBD5E1` | 큰 번호(01/02/03), 페이지 번호, 연한 테두리·채움 |
| Divider | `#E2E8F0` | 구분선(두께 1pt), 간지의 초대형 번호, 연회색 채움 |
| Surface | `#F1F5F9` | 카드·스탯 박스 배경 (연회색 면) |
| White | `#FFFFFF` | 슬라이드 배경 기본, 어두운 면 위 텍스트 |

### 포인트 컬러

| 역할 | HEX | 용도 |
|---|---|---|
| UBION Blue | `#0079FF` | "consortium" 표기 등 로고 관련 텍스트 전용. 콘텐츠에는 사용하지 않음 |

> 참고: 슬레이트 계열(`334155/475569/94A3B8/CBD5E1/E2E8F0/F1F5F9`)은 Tailwind CSS slate 스케일과 동일한 값이다. 테마(theme1.xml)는 기본 Office 팔레트 그대로이며, 실제 색은 모두 슬라이드에 직접 지정되어 있다.

## 3. 슬라이드 공통 구조

모든 본문 슬라이드가 동일한 프레임을 공유한다.

1. **상단 헤더**: 좌측 KOICA 로고 + 작은 회색 라벨, 우측 UBION 로고 + `consortium`(14pt, `#0079FF`). 아래로 얇은 구분선(`#E2E8F0`, 1pt).
2. **제목 블록**: 28pt Bold 2색 제목(다크 슬레이트 기본 + 핵심 키워드만 그린) → 그 아래 19pt Bold 그린 리드 문장("한 줄 요약").
3. **콘텐츠 영역**: 카드·표·프로세스 등 (아래 §4).
4. **KEY 메시지 띠** (선택): 하단에 `#E3F5EA` 연그린 배경 띠 + "KEY" 라벨 + 핵심 문장.
5. **푸터**: 좌측 `사업명 · 문서명`(9pt, `#94A3B8`), 우측 페이지 번호(10pt Bold, `#CBD5E1`), 위로 얇은 구분선.

표지(slide1)는 예외: 좌측에 다크 그린 세로 패널 + 우측 연그린 패널, 중앙에 42pt 2색 제목.

## 4. 콘텐츠 컴포넌트 스타일

| 컴포넌트 | 스타일 |
|---|---|
| **2단 비교 카드** | 상단에 `#2A9760` 그린 헤더 바(흰색 Bold 텍스트) + 아래 `#F1F5F9` 연회색 본문 영역, 불릿 리스트 |
| **번호 리스트** | `#CBD5E1` 34pt 대형 번호(01/02/03) + 우측 17pt 본문, 행간 여유 |
| **4단 컬럼 카드** | 상단 굵은 그린 컬러 칩(진한 그린→연한 그린 그라데이션 순서: `2A9760` → `93D0B2` → `E3F5EA` 계열) + 카드 제목 + 설명 |
| **표** | 헤더 행 `#2A9760` 채움·흰색 텍스트, 본문 행 흰색/연회색 교차, 테두리 `#E2E8F0` |
| **프로세스(단계) 흐름** | `#2A9760`/`#1F9155` 그린 박스 + 중간 단계는 `#93D0B2` 연그린, 화살표(rightArrow)로 연결 |
| **스탯 카드** | `#F1F5F9` 배경 박스 + 60pt Bold `#1F9155` 수치 + 하단 캡션 |
| **체크리스트/필 리스트** | 흰색 라운드 필(pill) + 좌측 작은 그린 원형 아이콘 + 부드러운 그림자 |

### 도형·효과 규칙

| 항목 | 값 |
|---|---|
| 도형 | 직사각형(rect) 위주 + 라운드 사각형(roundRect, 모서리 반경 소~중), 원(ellipse)은 아이콘 배경용 |
| 테두리 | 사용 시 `#E2E8F0`, 1pt (12700 EMU) 단일 두께 |
| 그림자 | outerShdw — 색 `#1F9155`, **투명도 90% (alpha 10%)**, blur ≈ 8.6pt, 거리 ≈ 2.2pt, 방향 아래(90°). 그린 기운이 도는 아주 부드러운 그림자 |
| 그라데이션 | 없음 (전부 단색 채움) |
| 배경 | 슬라이드 배경은 흰색, 배경 XML 지정 없음 |

## 5. 무드 & 디자인 원칙 요약

- **화이트 60–70% + 그린 20–30% + 슬레이트 뉴트럴**: 여백이 많고 밝고 정돈된 공공기관 제안서 톤.
- **2색 제목이 시그니처**: 제목 문장은 다크 슬레이트, 핵심 키워드만 그린으로 강조. 모든 제목 레벨(42/32/28pt)에서 동일하게 반복.
- **큰 숫자를 연하게**: 순번·간지 번호는 `#CBD5E1`/`#E2E8F0`로 흐리게 깔아 장식 요소처럼 사용.
- **채도 대비로 위계 표현**: 진한 그린(헤더·강조) → 연그린 틴트(보조·배경 띠) → 연회색(면) 순으로 단계적 사용.
- **자간은 타이트하게, 행간은 여유 있게**. 폰트는 Noto Sans KR 하나로 통일.
- 포인트 블루(`#0079FF`)는 브랜드(로고) 영역에만 한정 — 콘텐츠 색으로 확장하지 않는다.
